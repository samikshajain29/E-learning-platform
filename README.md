# 📘 E-Learning Platform (MERN)

A full-stack MERN E-Learning Platform with Google Authentication, Razorpay payments, Gemini search, password reset, and complete course management for smooth online learning.

---

## 🚀 Features

- 🔐 **Google Authentication (OAuth)**
- 💳 **Razorpay Payment Gateway**
- 🤖 **Gemini AI Search Integration**
- 🔑 **Secure Password Reset**
- 📚 **Course Creation & Management**
- 🎥 **Video Lessons & Content Delivery**
- 👩‍🏫 **Student & Instructor Dashboards**
- 🛡️ **JWT Authentication & Role-Based Access**
- 📊 **Progress Tracking**
- 🌐 **Fully Responsive UI**

---

## 🛠️ Tech Stack

### **Frontend**
- React.js  
- Redux / Context  
- Tailwind CSS  
- Axios  

### **Backend**
- Node.js  
- Express.js  
- MongoDB  
- Mongoose  

### **Integrations**
- Google OAuth  
- Razorpay API  
- Gemini API
